# Ben-wealthy - Billionaire Game

A simple game where you start from zero and make decisions to become a billionaire.

## How to Play
- You start with $1000
- Invest in businesses
- Make smart choices to grow your money
- Reach $1 Billion to win!

## How to Run
1. Download the file `main.py` or `index.html`
2. If Python: run `python main.py`
3. If Web: open `index.html` in your browser
